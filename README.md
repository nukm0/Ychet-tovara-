# Учёт товара

Личное приложение на русском языке. Откройте index.html в браузере.

Возможности: карточки товаров, вкусы, поступления, закупочные и продажные цены, расходы партии, продажи, списания, изменение количества, поиск, статистика и резервные копии JSON.

При поступлении доставка и прочие расходы распределяются по количеству. При повторном поступлении используется средневзвешенная себестоимость текущего остатка с округлением до копейки. Прибыль с остатков — прогноз при продаже по заданным ценам. Уже заработано — выручка совершённых продаж минус их себестоимость, расходы продажи и списания. Закупка сама по себе не уменьшает реализованную прибыль. Налоги не учитываются.

Текущая версия сохраняет данные в localStorage браузера. Общая база, вход и синхронизация двух устройств ещё не подключены. Очистка браузера удалит данные: регулярно скачивайте резервную копию. Восстановление заменяет текущие данные. Переход с локального файла на сайт или на другой адрес требует переноса через резервную копию.

Для Vercel: загрузите файлы проекта в репозиторий, импортируйте его в Vercel, выберите Other, без команды сборки, каталог результата — корень проекта. Ничего не опубликовано автоматически. Публикация этой версии не создаёт вход или общую базу; до использования на двух устройствах их нужно подключить.

Проверено: синтаксис JavaScript и сценарий поступления 10 единиц по 100 ₽ + 300 ₽ расходов, продажи 3 единиц по 200 ₽ с 30 ₽ расходов: себестоимость 130 ₽, прибыль продажи 180 ₽, остаток 7 единиц, ожидаемая выручка 1400 ₽. Проверено списание. Внешний вид в браузере автоматически не проверялся.
